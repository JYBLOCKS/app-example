# Workflow: Deliver a New Feature

1. Load project context and the relevant product story.
2. Confirm the feature is in approved scope.
3. Create or approve frontend/backend specifications and API contracts.
4. Record any architectural decision that changes boundaries or standards.
5. Create a task plan with vertical slices and acceptance mapping.
6. Use TDD to implement domain, API, UI, and integration behavior.
7. Run specialist validation and independent acceptance checks.
8. Review the diff against specifications and rules.
9. Produce a final implementation report.
