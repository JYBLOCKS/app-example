# Workflow: Release a Version

1. Confirm approved scope and completed acceptance evidence.
2. Verify CI, security, migration, and build results.
3. Confirm environment configuration and secrets.
4. Validate deployment, health checks, logs, metrics, and rollback path.
5. Execute controlled rollout and observe guardrails.
6. Record version, commit, artifact, migration, and release outcome.
7. Open follow-up work for deferred or discovered risks.
