# Workflow: Initialize a New Project

1. Complete `PROJECT_CONTEXT.md` with product, technology, quality, and delivery context.
2. Run the context-discovery skill and identify missing decisions.
3. Define the smallest MVP in `specs/product/`.
4. Approve baseline frontend, backend, and infrastructure architecture specifications.
5. Review proposed ADRs and change their status only after human approval.
6. Configure the registry for enabled agents and skills.
7. Establish local quality commands and CI gates.
8. Run the context and feature-readiness harnesses.
9. Record initialization results under `.agents/reports/`.
