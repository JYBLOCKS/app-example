# Workflow: Fix a Defect

1. Reproduce the defect and record expected versus actual behavior.
2. Identify the governing specification or clarify the intended behavior.
3. Add a regression test that fails for the correct reason.
4. Implement the smallest safe fix.
5. Run targeted tests and relevant regression suites.
6. Review for adjacent failure modes and security/data impact.
7. Produce a defect report with root cause and evidence.
